# NexHaven Real Estate

Next.js + Tailwind + Framer Motion landing page (same structure as green-harvest / pharonix).

- `npm install` then `npm run dev`
- All text lives in `data/data.json`
- Photos live in `public/images`. They are cropped from the design mockup by `scripts/crop-images.js`
  (`node scripts/crop-images.js`). To use real HD photos, overwrite the files in `public/images`
  with the same names.
